## Method that worked

1. **Recompute before writing.** Every publishable result here came from disagreeing with a filed number. Several near-misses were caught only because the author computed first — most sharply, an elegant Pell identity (`8119² − 2·5741² = −1`) that is *true* but attached to the wrong question.
2. **Extend the range.** The cheapest new mathematics available. A divisibility filed "no witness for n < 6000" had one at `n = 8178` under the identical criterion. A census filed for "prime blocks P ≤ 30020" missed `C(715,2) = 255255`.
3. **Check the reduction's direction.** "Contains" vs "is a subgraph of" changed an extremal number from 13 to 12. Bounding `F` needs the lcm from *below*.
4. **Ask what a witness constrains.** Several filed witnesses have the other arm of a `min` already satisfied and constrain nothing.

## Six failure modes, measured

1. **Claims failing inside their own stated range** — "all n ≤ 2000" failing at 341, the smallest Fermat pseudoprime, known since 1819.
2. **Enumerations claimed but not run** — a "3ⁿ exhaustive search" whose answers are exactly what adjacent-pairs-only gives.
3. **Retractions that are themselves wrong** — every retraction examined this run withdrew a *correct* result: `p=47` (on `47²+1 = 2222`, which is `47²+13`), `K(97;6)`, `f(22)`, `ρ*`.
4. **The wrong object certified** — a triple product for a pair predicate; `x+y≡0` for `x·y≡1`; `P ∨ ¬P` for `R(3,3) ≤ 6`.
5. **An asymptotic estimate filed as an exact count** — `N(10⁷)` recorded as `⌊6·10⁷/π²⌋`, "cross-checked" twice.
6. **Same-campaign contradictions decidable in seconds** — one row holding the counterexample to the PROVED row beside it.

None of this touches the mathematics underneath. The corpus's *specific* results survive recomputation far more often than its *generalizations* do.
